# Pen Collector Extreme

Pen Collector is a lightweight HTML5 canvas-based arcade game.
The objective is simple: move the pen holder and collect the correct pens
while avoiding dangerous ones.

## 🎯 Gameplay
- Move the pen holder horizontally using mouse or touch
- Catch different types of falling pens
- Avoid red pens to preserve lives
- Use special pens to gain advantages

## 🖊 Pen Types
- Blue Pen: +1 Score
- Silver Pen: +5 Score
- Green Pen: Activates slow-motion + bonus score
- Gold Pen: +1 Life
- Red Pen: -1 Life (avoid)

## ✨ Features
- Smooth canvas animations
- Realistic wire-mesh pen holder
- Floating colorful background particles
- Slow-motion visual effect
- Procedural sound effects (no audio files required)
- Fully responsive (desktop & mobile)
- No external libraries required

## 🎮 Controls
- Desktop: Move mouse left/right
- Mobile: Drag finger left/right

## 🔊 Audio
- Uses Web Audio API
- Sounds are generated in real time
- No sound files required
- Audio activates after user interaction (Start Game)
